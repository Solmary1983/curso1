# Tetris (JavaScript)

Esta carpeta contiene una aplicación simple de Tetris en JavaScript (HTML + CSS + JS).

Cómo usar

- Abre `index.html` en tu navegador (doble clic o sirviendo la carpeta con un servidor estático).
- Controles: ← → mover, ↑ rotar, ↓ bajar, espacio caída rápida, Q rotar a la izquierda.

Qué incluye

- index.html
- style.css
- tetris.js

Puedo:
- Ajustar la dificultad o añadir sonido.
- Integrarlo en una página principal del repo o crear un build con bundler si prefieres.
- Crear una rama o Pull Request para integrar los cambios.
